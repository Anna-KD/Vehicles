# Vehicles

A WPF application demonstrating Object-Oriented Programming principles.

## Features

- Abstract class Vehicle
- Inheritance
- Polymorphism
- Interfaces:
  - IDriveable
  - ISwimmable
- Shared collection of vehicles
- WPF user interface

## Vehicle Types

- Car
- Boat
- AmphibiousCar

## Project Structure

Vehicles.Core
- Vehicle
- Car
- Boat
- AmphibiousCar
- IDriveable
- ISwimmable

Vehicles.WpfApp
- User Interface
- Event Handling
- Logging

## Technologies

- C#
- .NET
- WPF
